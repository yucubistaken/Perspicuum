# Perspicuum

Windows 11 için geliştirilmiş, **Liquid Glass** cam tasarımlı canlı video/resim duvar kağıdı yöneticisi.

## Özellikler
- **Geniş Format Desteği:** MP4, MKV, WebM, MOV, AVI (4K, AV1, HEVC dahil) ve JPG/PNG/BMP.
- **Kalıcı Kütüphane:** Sürükle-bırak ile dosya ekleme, küçük kapak resimleri ve fareyle üzerine gelince anlık video önizleme.
- **Sistem Tepsisi:** Pencere kapatıldığında video arka planda kesintisiz oynamaya devam eder.
- **Modern Arayüz:** Windows 11 Acrylic cam efekti ve sade beyaz tasarım.

## Kurulum ve Kullanım
1. Sağ menüdeki **[Releases](https://github.com/yucubistaken/Perspicuum/releases)** bölümünden `Perspicuum-v1.0.zip` dosyasını indirin.
2. Arşivi bilgisayarınızda kalıcı bir klasöre çıkarın (klasör içindeki tüm dosyalar bir arada kalmalıdır).
3. `Perspicuum.exe` dosyasını çalıştırın.

> **Not:** Uygulama dijital olarak imzalanmadığı için ilk çalıştırmada Windows SmartScreen uyarısı çıkarsa **Ek bilgi → Yine de çalıştır** seçeneğini kullanın.
